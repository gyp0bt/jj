## 今回の作業内容

### プレビューボタン追加（テーブルビュー・詳細ビュー）
- テーブルビューの名前列にプレビューボタン（Eyeアイコン）を追加
- ボタンクリックで`BodyPreviewModal`が直接開く（ESCまたは外側クリックで閉じる）
- ホバー時のツールチップが一瞬で消える問題を回避するため、ボタンによる安定したモーダル表示を実現
- 詳細ビューのコンテンツセクションに「拡大」ボタンを追加（Expandアイコン）

### 詳細ビュー2カラムレイアウト
- 従来の縦並びレイアウトから2カラムレイアウトに変更
- 上部: エンティティカード（ヘッダー、タグ、統計バッジ等）
- 下部左カラム: コンテンツ（ボディのフォーマット対応レンダリング）
- 下部右カラム: プロパティテーブル + 関連エンティティビュー
- レスポンシブ対応: `lg`ブレークポイント以下では1カラムにフォールバック
- `max-w-5xl` → `max-w-6xl` に拡大

### Import時の進捗率表示
- フォルダインポート時にプログレスバーを表示
- エンティティ保存 + Relation保存の進捗をリアルタイムで更新
- 「インポート中... X / Y」のテキストとパーセンテージ表示
- 完了時にプログレス状態を自動リセット

### テーブルビューのフォルダ畳み込みバグ修正
- **原因1**: `collapsedIds`が`useState`初期化時のみ設定され、エンティティ変更時（ページ遷移、データ読み込み等）に新しいdirectoryエンティティが折りたたみ対象にならなかった
- **修正**: `useEffect`を追加し、エンティティ変更時に新しいdirectoryを自動で折りたたみ状態に追加。不要なID（別ページ）は削除
- **原因2**: `buildHierarchy`がページ内のエンティティのみで`hasChildren`を判定していたため、子がページ外にあるフォルダの畳み込みボタンが表示されなかった
- **修正**: 全Relation（ページ外含む）から「子を持つ親ID」を構築し、`hasChildren`の判定に使用

### タグ・Relationクリックナビゲーション
- **テーブルビュー**: タグをクリックすると`/search?tags=タグ名`へ遷移
- **テーブルビュー**: Relation値をクリックすると関連エンティティの詳細ビュー`/view?id=xxx`へ遷移
- **詳細ビュー**: ヘッダーのタグ（userTags/sysTags）をクリックすると`/search?tags=タグ名`へ遷移
- EntityTableに`onTagClick`/`onRelationClick`コールバックpropsを追加
