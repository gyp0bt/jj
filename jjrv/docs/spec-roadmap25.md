## 設計方針

### 目的
エンティティ詳細画面をGitリポジトリページ風の情報集約レイアウトに刷新し、フォーマットに応じた本文レンダリングを実現する。

### 方針
1. **フォーマット自動検出** — sysProps.format / 拡張子 / 本文内容から形式を判定し、適切なレンダラーで表示。
2. **多フォーマット対応** — Abaqus INP、CSV、JSON、Markdown、Python、プレーンの各形式をサポート。
3. **プレビュー統合** — カード内・コピーツールチップでもフォーマット対応プレビューを提供。
4. **情報密度の向上** — プロパティテーブル、統計バッジ、Relation可視化を1画面に集約。
5. **不要機能の廃止** — カードグループ化機能を削除し、設計と実装のズレを解消。
6. **大容量body対応** — 行数が多いbodyは折りたたみ表示、バイナリbodyは非表示とする。

## 25-08: body大容量時の折りたたみ - 詳細仕様

### 目的
詳細画面で長大なbodyを持つファイルを扱いやすくするため、以下の畳み込み機能を実装する：
1. **フォーマット別階層畳み込み** — ファイルの構造に応じた意味のある単位で畳み込み
2. **全体畳み込み** — 50行以上のファイルは初期状態で折りたたみ、「続きを表示▽」で展開
3. **トグル操作** — 対応フォーマットには畳み込みトグルボタンを配置

### 対応フォーマットと畳み込み単位

| フォーマット | 畳み込み単位 | 畳み込み基準 |
|-------------|-------------|-------------|
| Abaqus INP | キーワードセクション | `*`から始まる行（例: `*Material`, `*Elastic`）をセクションの開始として検出 |
| JSON | オブジェクト/配列の階層 | トップレベルのキー（`{ "key": {...} }`）を畳み込み単位とする |
| YAML | ドキュメント/階層 | トップレベルのキー（インデント0の行）を畳み込み単位とする |
| Markdown | 見出し階層 | `#`, `##`, `###`等の見出し行を畳み込み単位とする |

### 畳み込みUI仕様

#### 1. 全体畳み込み（50行以上）
- **条件**: body行数が50行を超える場合
- **初期状態**: 最初の50行のみ表示、残りは折りたたみ
- **UI**: 折りたたみ部分の下に「続きを表示 ▽ (残り XXX 行)」ボタンを配置
- **展開後**: 「畳む △」ボタンで再度折りたたみ可能

#### 2. 階層畳み込み（対応フォーマットのみ）
- **条件**: INP/JSON/YAML/Markdownのいずれか
- **UI配置**: body表示エリアの右上に「畳み込みトグル 🔽/🔼」ボタンを配置
- **初期状態**: すべて展開（ユーザーが必要に応じて畳み込み）
- **操作**:
  - トグルボタンクリック: すべてのセクションを一括で畳み込み/展開
  - 個別セクションクリック: 各セクションごとに畳み込み/展開（セクション行の左側に▶/▼アイコン）

#### 3. 畳み込み表示の見た目
- **畳み込み行**: `▶ *Material (15行)`のように、セクション名と行数を表示
- **展開行**: `▼ *Material`のように、セクション内容を表示
- **インタラクション**: セクション行全体をクリックでトグル

### 実装方針
1. **BodyRendererコンポーネント拡張** (`src/components/BodyRenderer/index.tsx`)
   - `CollapseMode`型定義: `'none' | 'full' | 'hierarchical' | 'both'`
   - フォーマット別のセクション検出ロジック（INP/JSON/YAML/MD）
   - 状態管理: `expandedSections: Set<number>`, `isFullExpanded: boolean`
2. **UIコンポーネント**
   - セクション折りたたみ行（`CollapsedSection`）
   - 全体折りたたみボタン（`ShowMoreButton`）
   - 階層トグルボタン（`HierarchicalToggleButton`）
3. **パフォーマンス考慮**
   - 大容量ファイル（1000行超）の場合は仮想スクロール検討（将来拡張）
   - セクション検出は初回レンダリング時のみ実行（`useMemo`）
