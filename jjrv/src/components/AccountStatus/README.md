# AccountStatus

> [← README.md](../../../README.md) /[← Components一覧](../README.md)

## 概要

右上に表示されるアカウントアイコンとドロップダウンメニュー。ログイン情報の表示とログアウト機能を提供。

## Props

なし（useAuthフックから認証状態を取得）

## States

- closed: ドロップダウン非表示
- open: ドロップダウン表示

## 表示内容

- ログイン中: ユーザー名の頭文字を丸いアイコンで表示
- 未ログイン: ログイン導線の丸アイコンを表示
- ドロップダウン:
  - ユーザー名
  - ロール（管理者バッジ）
  - ログアウトボタン

## Events

- onClick（アイコン）: ドロップダウンを開閉
- onClick（ログアウト）: ログアウト処理を実行

## 備考

- useAuthフックを使用
- 外部クリックでドロップダウンを閉じる
