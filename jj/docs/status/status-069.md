# status-069: ダッシュボード機能拡張（AgGrid・画像ギャラリー・自動リフレッシュ）

**日付**: 2026-02-12
**担当**: Claude Code

---

## 概要

Phase 2.5のダッシュボードTODO3件を実装。テーブルビューをAgGrid対応にアップグレード（フォールバック付き）、has_output関係の画像を5列グリッドで表示するギャラリーページを追加、graph.yamlのファイル変更検知による自動リフレッシュ機能を追加。

---

## 実装内容

### 1. AgGridテーブル表示

**概要**: テーブルビューのDataFrame表示をAgGridにアップグレード。streamlit-aggridが未インストールの場合はst.dataframeにフォールバック。

| 機能 | 詳細 |
|------|------|
| チェックボックス行選択 | 複数行選択対応 |
| カラムフィルタ | 全カラムにフィルタ機能 |
| カラムソート | 全カラムにソート機能 |
| カラムリサイズ | ドラッグでカラム幅変更 |
| ページネーション | 自動ページサイズ |
| フォールバック | st_aggrid未インストール時はst.dataframe |

**依存追加**: `streamlit-aggrid>=1.0.0` を requirements.txt に追加

### 2. 画像ギャラリー

**概要**: has_output関係で紐付いた画像ファイル（PNG/GIF/JPG/JPEG/BMP/SVG/TIFF）を5列グリッドで表示。

| 機能 | 詳細 |
|------|------|
| 画像表示 | 5列グリッドレイアウト |
| パラメータ表示 | 各画像にgo_ノードのindex/version/type/statusを表示 |
| フォーマットフィルタ | サイドバーで画像フォーマット選択 |
| 最大表示数制限 | 1-200件の表示数制御 |
| ファイル不在時警告 | 画像パスが存在しない場合に警告表示 |

**新規メソッド**: `DashboardDataProvider.get_output_images(node_id=None)` を追加

### 3. graph.yaml変更検知・自動リフレッシュ

**概要**: graph.yamlのファイル更新時刻（mtime）を監視し、変更を検知して自動でデータを再読み込み。

| 機能 | 詳細 |
|------|------|
| 変更検知 | st.session_stateにmtimeを保持し、毎回比較 |
| 手動再読み込み | サイドバーの「再読み込み」ボタン |
| 自動リフレッシュ | トグルで有効化、間隔3-60秒で設定可能 |
| 変更通知 | graph.yaml更新時にサイドバーに通知表示 |
| graph.yaml検出 | yaml/yml/json形式を自動検出 |

**自動リフレッシュ実装**: JavaScriptタイマーで「再読み込み」ボタンを定期的にクリック（外部パッケージ不要）

## 設計上の懸念

- AgGridはst_aggridパッケージに依存するが、未インストール時はst.dataframeにフォールバックする。ユーザーが明示的にインストールする必要がある。
- 画像ギャラリーはproject_rootからの相対パスで画像ファイルを参照する。画像が大量の場合はmax_display設定でパフォーマンスを制御。
- 自動リフレッシュはJavaScriptタイマーで「再読み込み」ボタンをクリックする方式。Streamlitのバージョンやテーマによってはボタンセレクタが変わる可能性がある。
- graph.yamlのmtime比較は浮動小数点なので、ファイルシステムによっては精度の問題がありうる（実用上は問題ない）。
