# noteコマンド層 仕様書

## 1. 概要

本ドメインは、プロジェクトフォルダ全体を解析してグラフデータを生成し、Obsidian等の外部ツール向けにノートを出力する機能を提供します。

### 目的

- プロジェクト全体のファイルを走査し、グラフデータ化
- ファイル間の依存関係の自動検出
- Obsidian向けMarkdownノートの生成
- 実行履歴との統合（run履歴の可視化）

### 責務範囲

- `services/note/` : プロジェクト解析とノート生成
- `output/notes/` : Obsidian向けノートの出力先（デフォルト）

---

## 2. コマンド構文

### 2.1 基本形式

```bash
jj n [options]
```

### 2.2 オプション（現在/将来）

```bash
jj n                          # デフォルト: プロジェクト全体を解析
jj n --target ./subdir        # 特定ディレクトリのみ解析
jj n --output ./obsidian      # 出力先を指定
jj n --format obsidian        # 出力フォーマット指定（将来: neo4j, json）
jj n --update                 # 差分更新のみ
```

---

## 3. 解析フロー

### 3.1 プロジェクト走査

1. **対象ディレクトリの決定**: デフォルトはカレントディレクトリ
2. **ファイルリスト取得**: 再帰的に全ファイルを列挙
3. **除外ルールの適用**: `.jj/`, `.git/` 等を除外
4. **ファイル解析**: 各ファイルを `FileParse` で解析

### 3.2 除外ルール

以下のディレクトリ/ファイルは解析から除外:

```python
EXCLUDED_DIRS = [
    ".jj",
    ".git",
    "__pycache__",
    ".venv",
    "venv",
    "node_modules",
]

EXCLUDED_FILES = [
    "*.pyc",
    ".DS_Store",
    "Thumbs.db",
]
```

### 3.3 ファイル分類

ファイルを以下のカテゴリに分類:

| カテゴリ | 接頭辞/拡張子 | 説明 |
|---------|-------------|------|
| 計算入力 | `go_*.inp`, `go_*.cas.h5` | CAE計算の入力ファイル |
| メッシュ | `mesh_*.cdb`, `mesh_*.msh` | メッシュデータ |
| 材料定義 | `material_*.mat` | 材料プロパティ |
| ステップ定義 | `step_*.inc` | 解析ステップ定義 |
| 実行履歴 | `.jj/storage/run/*.json` | 実行ログ |
| その他 | - | 上記に該当しないファイル |

## 5. 依存関係の検出

### 5.1 ファイルグループによる関係

同一indexを持つファイルは暗黙的に関連づけられます。

#### 例

```
go_sample_v1_idx1.inp
mesh_elem5000_v1_idx1.cdb
material_steel_v1_idx1.mat
```

これらは `idx=1` で関連づけられ、Obsidianノートでは相互リンクが生成されます。

### 5.2 実行履歴による関係

`run` ノードと生成ファイルは `Relation(label=generated)` で関連づけられます。

### 5.3 明示的な依存関係（将来実装）

ファイル内のコメントや特定記法で依存関係を明示:

```python
# depends: mesh_elem5000_v1_idx1.cdb
# depends: material_steel_v1_idx1.mat
```

## 6. 差分更新機能

### 6.1 初回実行

全ファイルを解析し、ノートを生成します。

### 6.2 差分更新（`--update`）

前回実行時のスナップショットと比較し、変更があったファイルのみ再生成します。

#### 更新判定

- 新規ファイル: 前回スナップショットに存在しない
- 変更ファイル: mtimeが更新されている
- 削除ファイル: 現在のプロジェクトに存在しない

#### スナップショット保存

```
.jj/storage/snapshot.json
```

```json
{
  "timestamp": "2026-02-04T12:00:00",
  "files": {
    "go_sample_v1_idx1.inp": {
      "mtime": "2026-02-04T11:50:00",
      "size": 1024
    },
    ...
  }
}
```

## 8. 設計上の注意事項

### 8.1 パフォーマンス

- 大量ファイル（10,000件以上）を想定し、並列処理を導入
- スナップショットはmtimeのみを記録し、ファイル内容のハッシュ化は行わない

### 8.2 Obsidianとの互換性

- ファイル名に使えない文字（`/`, `:`, `*` など）はサニタイズ
- `[[wikilink]]` 形式のリンクを優先

### 8.3 拡張性

- 出力フォーマットはプラグイン方式で追加可能に
- カスタムテンプレートをサポート
