## 設計判断

- **完了済み**: 1行サマリー + statusリンクで参照可能に
- **未着手/アクティブ**: 詳細を残す
- **古い情報**: `<details>`折りたたみまたは削除

### ナビゲーション設計
- docs/README.md → 全ドキュメントへのハブ
- status-index.md → TODO + 進捗 + 履歴
- roadmap.md → 計画 + 依存関係
- specs/README.md → 仕様書カタログ
